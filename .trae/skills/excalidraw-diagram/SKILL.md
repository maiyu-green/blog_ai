# Excalidraw Diagram Skill

## Description
Generate hand-drawn style diagrams using Excalidraw format. This skill helps create sketch-style flowcharts, mind maps, architecture diagrams, and more with a natural hand-drawn aesthetic.

## Features

### Supported Diagram Types
- **Flowcharts** - Process flows, decision trees
- **Mind Maps** - Hierarchical idea visualization
- **Architecture Diagrams** - System design, infrastructure
- **UML Diagrams** - Class diagrams, sequence diagrams
- **Wireframes** - UI/UX mockups
- **Custom Drawings** - Free-form sketches

### Output Format
- Excalidraw JSON format (.excalidraw)
- Exportable to PNG, SVG, PDF
- Compatible with https://excalidraw.com

## Usage

### Basic Usage
```
生成一个用户登录流程的 Excalidraw 图
```

### Advanced Usage
```
创建一个系统架构图，包含前端、后端、数据库三个模块，用手绘风格
```

## How to Open Excalidraw Files

### Online
1. Visit https://excalidraw.com
2. Click "Open" → select .excalidraw file
3. Or paste JSON directly

### VS Code
1. Install "Excalidraw" extension
2. Open .excalidraw files directly

### Export
- PNG: Raster image for documents
- SVG: Vector for scalable graphics
- PDF: For printing

## Examples

### Example 1: Simple Flowchart
Input: "创建一个判断闰年的流程图"

Output: Excalidraw JSON with decision diamonds and process boxes

### Example 2: Mind Map
Input: "生成一个关于机器学习的思维导图"
