# Fixed Context - 重生80年代倒爷

## 世界观 (≤800字)

**时代**: 1983-1992年，中国改革开放初期

**核心背景**: 计划经济向市场经济转型的阵痛期。粮票、布票等票证制度仍在实行，但价格双轨制已创造出巨大的套利空间。农村改革释放了大量剩余劳动力，城市改革刚刚启动，"个体户"开始出现但社会地位低下。

**社会风貌**: 物资匮乏，商品短缺，"走后门"成为获取物资的主要方式。"投机倒把"仍是罪名，做生意被视为"不务正业"。信息极度闭塞，谁先掌握信息谁就能赚钱。

**关键历史节点**:
- 1984年: 城市经济体制改革启动
- 1985年: 价格双轨制确立，"倒爷"群体崛起
- 1988年: 价格闯关，通货膨胀
- 1992年: 邓小平南巡，改革开放进入新阶段

**商业环境**: 南北价差、城乡价差、计划内外价差构成三大套利机会。批文、指标成为硬通货。主要商业模式包括倒爷、个体户、乡镇企业、外贸加工。

**地理设定**: 起点为华北某省农村，发展路径为省城→北京/上海/广州。

## 角色 (≤1200字)

### 主角: 张峰

**基本信息**:
- 重生前45岁，成功企业家，因车祸去世
- 重生后18岁，1983年夏，高考落榜的农村青年
- 金手指: 拥有未来40年的商业记忆和历史走向

**性格特征**:
- 沉稳老练，有超越年龄的心理成熟度
- 善于观察，能敏锐捕捉商机
- 重情重义，但不会被感情冲昏头脑
- 敢于冒险，但会计算风险
- 有远见，懂得布局

**家庭背景**:
- 父亲: 老实巴交的农民，对儿子期望很高
- 母亲: 勤劳朴实的农村妇女
- 妹妹: 正在读初中，聪明伶俐
- 家境贫寒，欠债累累

**核心动机**:
1. 改变家庭命运，让家人过上好日子
2. 弥补前世遗憾，重新活出精彩人生
3. 抓住时代机遇，建立商业帝国

**能力优势**:
- 重生前的商业经验和人脉积累
- 对未来经济走势的先知优势
- 现代商业思维和营销理念
- 对政策走向的预判能力

### 重要配角

**李建国**: 张峰的表哥，在县城供销社工作，成为张峰早期的重要人脉，提供计划内物资信息。

**王老板**: 省城第一批个体户，张峰的引路人，教张峰做生意的门道。

**林晓燕**: 省城纺织厂职工，后成为张峰的合伙人，负责南方货源。

**赵德海**: 张峰的对手，本地"倒爷"，与张峰多次交锋。

## 大纲 (≤3000字)

### 第一卷: 起步 (1983-1984)

**主线**: 张峰重生后，利用信息差从农村起步，积累第一桶金。

**关键情节**:
1. **重生觉醒**: 张峰高考落榜后重生，确认时间点后决心改变命运
2. **第一笔生意**: 利用知道鸡蛋即将涨价的信息，收购村民鸡蛋卖到县城，赚取第一笔利润
3. **表哥人脉**: 通过表哥李建国接触到供销社的计划内物资，开始小规模倒卖
4. **家庭阻力**: 父母不理解张峰"不务正业"，张峰用实际收入说服家人
5. **省城初探**: 张峰第一次前往省城，见识到巨大的商机

**本卷目标**: 赚取5000元启动资金，建立初步人脉，获得家人支持。

### 第二卷: 崛起 (1984-1985)

**主线**: 张峰进军省城，成为专业"倒爷"。

**关键情节**:
1. **省城立足**: 张峰带着全部积蓄来到省城，从摆摊卖服装开始
2. **结识王老板**: 王老板看中张峰的胆识和眼光，收其为徒
3. **南北倒卖**: 张峰发现南方服装与北方的巨大价差，开始往返于广州与省城之间
4. **遭遇打压**: 本地"倒爷"赵德海视张峰为威胁，多次使绊子
5. **政策红利**: 1984年城市改革启动，张峰抓住机会扩大规模

**本卷目标**: 资产达到10万元，在省城站稳脚跟，建立稳定的南北供货渠道。

### 第三卷: 扩张 (1985-1988)

**主线**: 张峰从个体"倒爷"转型为企业主，涉足多个领域。

**关键情节**:
1. **成立公司**: 张峰注册成立贸易公司，从个体户升级为企业主
2. **多元经营**: 涉足家电、建材、日用百货等多个领域
3. **结识林晓燕**: 林晓燕成为张峰的重要合伙人，负责南方货源
4. **北京布局**: 张峰前往北京，建立政治人脉，获取批文资源
5. **价格闯关**: 1988年通货膨胀，张峰提前囤积物资，大赚一笔

**本卷目标**: 资产突破100万元，成为省内知名商人，建立完整的商业网络。

### 第四卷: 转型 (1988-1992)

**主线**: 张峰从"倒爷"转型为实业家，抓住股市和房地产机遇。

**关键情节**:
1. **实业投资**: 张峰意识到"倒爷"模式不可持续，开始投资实业
2. **股市初探**: 1990年沪深交易所成立，张峰成为第一批股民
3. **房地产开发**: 张峰进军房地产，在省会城市开发第一批商品房
4. **南巡机遇**: 1992年邓小平南巡，张峰加大投资力度
5. **家庭圆满**: 张峰功成名就，家人过上幸福生活

**本卷目标**: 资产突破1000万元，完成从"倒爷"到企业家的转型，实现人生逆袭。

## 风格锚定

**叙事风格**: 写实向年代文，注重历史细节和商业逻辑

**语言特点**: 
- 朴实无华，贴近生活
- 对话符合80年代人物身份
- 商业描写专业但不晦涩

**节奏把控**:
- 单章3000-4000字
- 每卷20-30章
- 保持适度爽感，但不脱离现实

**核心主题**: 时代机遇与个人奋斗，商业智慧与道德底线
